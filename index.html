    Google Drive sync

    Data is encrypted on this device with your login before it is uploaded, so Google stores only an unreadable file (research-desk-vault.json), kept in the Drive folder you choose. On another device: open this site, sign in with the same email and password, paste the same Client ID and click “Sync now”. Needs a connection that can reach Google (VPN in mainland China).

    Drive folder:

    While connected, changes upload automatically about 20 seconds after you stop editing. Google access lasts about an hour, then “Sync now” reconnects.

    How to get a Client ID (once, about 10 minutes)
    1. Open console.cloud.google.com and create a project (any name).
    2. APIs & Services → Library: enable Google Drive API and Google Picker API (the Picker is the “Choose folder…” window).
    3. OAuth consent screen: User type External, fill in app name and your email, keep it in Testing, and add your Google account under Test users.
    4. Credentials → Create credentials → OAuth client ID: type Web application, Authorized JavaScript origin https://dodyirawaan.github.io (no path, no trailing slash).
    5. Copy the Client ID (ends with .apps.googleusercontent.com) and paste it above.
